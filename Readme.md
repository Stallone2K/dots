# 🐆 dots

![Dots Preview](https://github.com/Stallone2K/dots/blob/Main/Dots.png)

## 🚀 Features
- Custom Configurations And Settings
- Optimized Workflow Settings
- Minimal And Aesthetic

## 📂 Structure
```
.
├── alacritty/       # Alacritty Terminal 
├── vsx/             # Vscode (Vim)
├── zsh/             # Zsh And OMZ 
```

## 🔧 Installation
```bash
git clone https://github.com/Stallone2K/dots.git ~/.dots
cd ~/.dots
```

## 🛠️ Usage
- Copy The Configs To The Appropriate Directories
- Restart Your Terminal For Changes To Take Effect
- Customize As Needed
